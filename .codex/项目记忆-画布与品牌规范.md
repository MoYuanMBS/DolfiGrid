# 项目记忆：画布与品牌规范

更新时间：2026-08-27

本文件记录已确认、应在后续 HTML 排版任务中默认继承的项目约定。完整、可执行的规则见 [成品画布与品牌视觉规范.md](成品画布与品牌视觉规范.md)。

## 已确认的默认约定

- 生成规范分为两版：未声明 `spec_version` 的归档文件继续使用 `legacy-v1`；后续新文件必须显式声明 `spec_version: "fixed-canvas-v2"`。
- `legacy-v1` 仅用于复现旧模板，保留原有动态最低高度和旧图片绑定行为，并在构建时提示归档兼容模式。
- `fixed-canvas-v2` 必须声明 `canvas_width`、`canvas_height` 与 `export_scale`，禁止混用 `layout_width`、`min_aspect_ratio`、`canvas_min_height`。
- 本项目生成的是固定尺寸的成品画布，不是响应式网页。
- 后续模板不再使用动态宽高比、最低比例或随内容自然增长的长图画布。
- 默认使用横版 4:3，逻辑尺寸为 `1600 × 1200px`；指定 16:9 时使用 `1600 × 900px`。
- 画布的宽度和高度必须同时锁定为像素值；高清通过 `export_scale` 整数倍率导出，再缩小派生，不能通过放大低清图解决。
- 每一张成品图必须有且仅有一个清晰可见的 Logo。未提供 layout 时，Logo 默认在顶部；提供 layout 时按 layout 放置。
- Logo 有三种固定版本；单张成品只能使用一个版本，可在模板中固定指定。
- Logo 不得有任何形式的边框、描边式外框、相框、围合容器或卡片边框；允许不围合 Logo 的装饰。
- 文字、价格、表格、提示和须知可以使用带边框的卡片设计。
- 用户给出 layout 时，必须保留其内容顺序、区域、对齐和信息层级；可调整主题、配色和装饰，但不可借由改风格改变 layout。
- 所有业务图片必须无边框、无相框，并且可替换。
- 业务图片使用 Markdown frontmatter 的 `images` 字段，放置在 `assets/insert-png/`，按模板的 `data-md-field="media"` 媒体槽位顺序绑定；HTML/CSS 不得写死业务图片路径。
- 业务文案、价格、标签、要求和须知保持由 Markdown/frontmatter 编辑；HTML/CSS 只提供结构与视觉样式。

## SVG 约定

- SVG 源文件位于 `assets/svg/`，所有 SVG URL 调用统一位于 `css/svg/`；主题文件仅提供 `--svg-*` 颜色变量。
- 每个 `assets/svg/` 资产均须在 `css/svg/` 注册语义类；未被当前模板调用也不能省略。
- 纯黑 SVG 用 mask 着色；彩色 SVG 拆为 `*-ink.svg` 与 `*-color.svg`，并让彩色层始终在主题色墨线层之上，避免黑色主体遮住彩色细节。
- 识别黑色时必须考虑 SVG 默认 `fill: black` 与继承色；`shield.svg`、`shock.svg` 的未声明 fill path 均属于黑色图层。
- 禁止对整张 SVG 使用 filter 改色；非黑色、白色、渐变与透明度保持原样。

## 使用提醒

新建或重做模板前，先阅读上述完整规范；如用户给出新的 layout 或明确例外，以用户当次要求为准，并同步更新规范与本记忆文件。
