# Markdown → 固定排版图片：总体方案

## 1. 核心原则

| 原则 | 做法 |
|---|---|
| 画布宽度写死 | `.canvas { width: 1280px }`，不用 `%` / `vw` |
| 预览宽度无关 | `body` flex 居中，面板宽窄都不影响布局 |
| 只能更长不能更短 | `min-height` + `flex-grow`，纯 CSS 一次渲染 |
| 结构绝不塌 | `layout.css` 内禁止任何 `@media` |
| 高清母版 | 4x 导出，向下派生，不做放大 |

## 2. 目录结构

```
标准格式/

new-project/export-images.js  # Playwright 出图

```

## 3. Frontmatter 规范（修订版）

```yaml
---
template: "susu_tactical_ui_template"
theme: "bright"
subtitle: "ESSENTIAL SERVICE MENU & PRICE LIST"
hud_tag: "TACTICAL SERVICE MENU // 战术导引菜单"
decor_block_height: "100px"

layout_width: "1280px"        # 逻辑画布宽，仅 px
min_aspect_ratio: "9:16"      # 新增：最小比例，只能更长
export_scale: 4               # 新增：母版倍率
export_derive:                 # 新增：派生档位（微信用）
  - 2

label.experience_badge_1: "OPTION A"
label.guarantee_badge: "GUARANTEED"
---
```

### 相对旧规范的改动

| 项 | 处理 |
|---|---|
| `print_width_mm` / `export_dpi` | **废弃**（210mm@300dpi 仅 2480px，分辨率不足），改用 `export_scale` |
| “窄画布是否单列由媒体规则决定” | **删除**，改为“模板 CSS 不得含媒体查询，双栏恒定” |
| “高度始终由内容自然增长” | **改为** `min_aspect_ratio`，不足时补足 |
| `canvas_min_height` | 保留，降级为手动覆盖项；未设则由 `min_aspect_ratio` 算出 |

其余条款（template/theme 只写主体名、主标题写正文、须知写 `## [section:notice]`、JS 只读模板输出新文件）**全部保留**。

## 4. CSS 核心（layout.css）

```css
body{ margin:0; display:flex; justify-content:center; background:#8884; }

.canvas{
  width: 1280px;            /* 写死 */
  flex: none;
  min-height: 2276px;       /* = 1280 × 16/9，由 build.js 注入 */
  display: flex;
  flex-direction: column;
}

/* 谁吸收多余高度，由模板声明；拉伸必须传导到内部双栏 grid */
.canvas > [data-layout-grow]{
  flex:var(--layout-grow,1) 1 auto; min-height:0;
  display:flex; flex-direction:column;
}
.canvas > [data-layout-grow] > .pkg-grid{ flex:1 1 auto; min-height:0; }

/* 双栏恒定且同一行卡片等高，无媒体查询 */
.pkg-grid{ display:grid; grid-template-columns:1fr 1fr; gap:var(--gap); align-items:stretch; }

/* 三种吸收方式 */
.card[data-fill="between"]{ justify-content:space-between; }
.card[data-fill="image"] .card-media{ flex:0 0 auto; min-height:0; }
.card[data-fill="image"] .card-media img{ width:100%; height:auto; object-fit:contain;
               object-position:var(--focus,50% 50%); }
.card[data-fill="pad"]{ justify-content:center; }
```

行为：内容不足 → flex 把多余高度分给 `data-layout-grow`，页脚贴底无空白；内容超出 → `flex-grow` 失效，自然向下增长。图片卡只按原比例改变自身内容高度，不会裁切图片；同一行文字卡随 Grid 等高，但文字始终从顶部连续排布，留白只出现在文字内容下方。

## 5. 导出

```js
const ctx = await browser.newContext({
  deviceScaleFactor: 4,
  viewport: { width: 1400, height: 900 },   // 略宽于画布，复现居中态
});
const page = await ctx.newPage();
await page.emulateMedia({ media: 'screen' });
await page.goto('http://127.0.0.1:<临时端口>/output/x.html');
await page.evaluate(() => document.fonts.ready);   // 中文字体必等
await page.locator('.canvas').screenshot({ path: 'output/x@4x.png' });
await page.close();
```

批量：复用 `browser` + `ctx`，每张新建 `page`。

### 输出档位

| 档 | 尺寸（最小高时） | 体积 | 用途 |
|---|---|---|---|
| master 4x | 5120 × 9104 | ~42MB | 母版 / Illustrator |
| web 2x | 2560 × 4552 | ~10MB | 微信（由母版 0.5 整数倍缩小） |

**长图保护**：派生时按长边 ≤10000px 二次收缩，否则微信上传失败。

## 6. 已知坑与修复

| 坑 | 现象 | 修复 |
|---|---|---|
| 中文路径拼接 | `Unable to get absolute uri between \标准格式\...` | 用 `path.resolve()` + `pathToFileURL()`，禁止字符串拼 file:// |
| 预览面板宽度漂移 | Simple Browser 宽度随侧边栏/缩放变化 | `.canvas` 写死 + body 居中，宽度无关 |
| 字体未加载就截图 | 批量出图偶发排版错位 | `await page.evaluate(() => document.fonts.ready)` |
| 滚动条占 15px | 真实浏览器 1280 窗口内容宽仅 1265px | `.canvas` 固定宽，不用 100% |
| filter / 大 blur 阴影 | 4x 渲染慢；若走 PDF 会被光栅化 | 改用实边框、纯色叠层、渐变 |

## 7. 预览体检徽章（preview.js，导出不加载）

```js
const w = document.querySelector('.canvas').getBoundingClientRect().width;
const b = document.createElement('div');
b.style.cssText = 'position:fixed;right:8px;top:8px;z-index:9999;font:12px monospace;'
  + 'padding:4px 8px;border-radius:4px;color:#fff;background:'
  + (w === 1280 ? '#3ba55d' : '#d33');
b.textContent = `canvas ${w}px / dpr ${devicePixelRatio} `
  + (w === 1280 ? '✓ 与导出一致' : '✗ 布局已偏移');
document.body.appendChild(b);
```

绿色 = 所见即所得；红色 = 预览不可信。

调试辅助（`<body class="dbg">`）：

```css
.dbg [data-grow]{ outline:1px dashed #3ba55d55; }
.dbg .canvas::after{ content:''; position:absolute; left:0; right:0; top:2276px;
                     border-top:1px dashed #d33; pointer-events:none; }
```

## 8. 全链路

```
Markdown（内容 + frontmatter）
   ↓ build.js：解析 / 校验 / 算 min-height / 注入
output/*.html（固定 1280px）
   ↓ Simple Browser 肉眼校对（绿徽章 = 可信）
   ↓ export.js：Playwright @4x 单次渲染
master@4x.png  5120 × 9104
   ↓ 缩小派生（长边 ≤10000px）
web@2x.png     2560 × 4552 → 微信
```

## 9. 可选：矢量 PDF（当前不做，接口预留）

同一份 HTML，加两行即可出真矢量，供 Illustrator 编辑：

```js
await page.pdf({ path:'out.pdf', width:'210mm', height:`${210*h/1280}mm`,
                 scale:0.620079, pageRanges:'1', printBackground:true,
                 margin:{top:0,right:0,bottom:0,left:0} });
```

`scale` 用于修正 PDF 默认 1px=1/96in 换算（否则 1280px 会变成 338.67mm 而非 210mm）。
中文转曲：`gs -sDEVICE=pdfwrite -dNoOutputFonts -dColorConversionStrategy=/LeaveColorUnchanged -o out-outlined.pdf out.pdf`（PDF→PDF 直转，勿走 PS 以免丢透明度）。
